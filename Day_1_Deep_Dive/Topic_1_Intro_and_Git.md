# Topic 1: Introduction to Python and Git Workflow

## What is Python?
Python is a high-level, interpreted programming language. High-level means it reads much like English, making it easier to learn and write. Interpreted means the code is executed line-by-line, which is great for debugging and rapid development.

### Key Features
- Dynamically Typed: You do not need to declare variable types explicitly.
- Large Ecosystem: Thousands of libraries available for web development, data science, and automation.
- Cross-Platform: Works on Windows, Mac, and Linux without modification.

## Version Control with Git
When building software, especially in teams, you need a way to track changes to your code over time. Git is a version control system that does exactly this.

### Basic Git Workflow
1. `git init`: Initializes a new, empty Git tracking repository in your current folder.
2. `git add .`: Stages all modified files, preparing them to be saved.
3. `git commit -m "message"`: Takes a snapshot of the staged files and saves them in Git history.
4. `git push`: Uploads your committed changes to a remote server (like GitHub).
5. `git clone <url>`: Downloads an existing repository from a server to your computer.
