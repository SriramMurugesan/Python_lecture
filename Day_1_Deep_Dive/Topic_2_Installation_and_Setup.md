# Topic 2: Python Installation and Setup

## Setting Up Python
To run Python code, you must first install the Python interpreter on your computer. The interpreter translates your Python text files into instructions the computer can execute.

### Important Installation Step (Windows)
When installing Python on Windows, you must check the box that says "Add Python to PATH". This allows your terminal or command prompt to recognize the `python` command from any directory.

## Development Environments (IDEs)
Writing code in a standard text editor like Notepad is difficult because it lacks features like error highlighting and auto-completion. We use Integrated Development Environments (IDEs) instead.
- VS Code: A powerful editor for writing scripts and building full applications.
- Jupyter Notebook: A browser-based environment where you can write and run code in small blocks (cells). This is highly favored in Data Science.

## Problem Solving Workflow
Before writing code, developers follow a structured process:
1. Understand the problem.
2. Write pseudocode (plain English steps of the logic).
3. Translate pseudocode into actual Python code.
