# Topic 3: Variables, Data Types, and Operators

## Variables
A variable is like a labeled box in your computer's memory where you can store data. You create a variable by giving it a name and using the equals sign (`=`) to assign a value.
- Variable names should be descriptive.
- Use underscores to separate words (e.g., `user_age`, not `user age`).

## Core Data Types
Python has several built-in types of data:
- Integer (`int`): Whole numbers (e.g., 10, -5).
- Float (`float`): Numbers with decimals (e.g., 3.14, -0.5).
- String (`str`): Text, enclosed in single or double quotes (e.g., "Hello").
- Boolean (`bool`): Represents truth values: `True` or `False`.

## Operators
Operators are symbols that perform operations on variables and values.
- Arithmetic: Addition (`+`), Subtraction (`-`), Multiplication (`*`), Division (`/`), Floor Division (`//`), Modulo/Remainder (`%`).
- Logical: `and`, `or`, `not`. These are used to combine multiple boolean conditions.

## Type Casting
Sometimes you need to convert data from one type to another. This is called type casting.
For example, converting the string "10" to the integer 10 using `int("10")`. Python will not automatically let you add a string and an integer together.
