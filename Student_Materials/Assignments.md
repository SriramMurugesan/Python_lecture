# 📝 Python Training - Daily Assignments

These exercises are designed to be completed by students during the Hands-On/Practice slots.

## 🗓️ Day 1

### Topic 1: Git Workflow
* **Easy:** 1. Create a GitHub account. 2. Initialize a local repo.
* **Medium:** 1. Create a simple text file, add it, and commit.
* **Hard:** 1. Push your local repository to a remote GitHub repo.

### Topic 2: Setup & Problem Solving
* **Easy:** 1. Install Python and verify version. 2. Install VS Code.
* **Medium:** 1. Write a script that prints your name and run it via terminal.
* **Hard:** 1. Write structured pseudocode for a daily task (like making tea).

### Topic 3: Variables, Data Types & Operators
* **Easy:** 1. Assign your age to a variable and print it. 2. Add two float variables.
* **Medium:** 1. Calculate the area of a rectangle given length and width.
* **Hard:** 1. Calculate compound interest based on hardcoded inputs.

## 🗓️ Day 2

### Topic 4: String Operations
* **Easy:** 1. Print the first and last character of a string. 2. Convert a string to uppercase.
* **Medium:** 1. Reverse a string using slicing.
* **Hard:** 1. Check if a string is a palindrome.

### Topic 5: Input/Output Functions
* **Easy:** 1. Ask for a name and print a greeting. 2. Take two numbers as input and multiply them.
* **Medium:** 1. Build a simple calculator that takes two numbers and prints operations.
* **Hard:** 1. Build an interactive tip calculator.

### Topic 6: Loops (Checkpoint 1)
* **Easy:** 1. Print numbers 1 to 10 using a `for` loop. 2. Print even numbers from 2 to 20 using a `while` loop.
* **Medium:** 1. Calculate the factorial of a number using a loop.
* **Mini Project 1 (Basics):** Build a Command-Line User Profile Generator using loops to ask for user inputs 3 times and validate age.

## 🗓️ Day 3

### Topic 7: Lists
* **Easy:** 1. Create a list of 5 fruits and print the 3rd one. 2. Add a new fruit to the end.
* **Medium:** 1. Find the largest and smallest number in a list without using max/min.
* **Hard:** 1. Remove all duplicates from a list using a loop.

### Topic 8: Dictionaries & Tuples
* **Easy:** 1. Create a dictionary with 3 key-value pairs. 2. Create a tuple with 3 elements.
* **Medium:** 1. Iterate over a dictionary and print keys and values.
* **Hard:** 1. Count the frequency of each character in a string using a dictionary.

### Topic 9: File Handling
* **Easy:** 1. Write "Hello World" to a text file. 2. Read the contents of that file.
* **Medium:** 1. Read a file line by line and store each line in a list.
* **Hard:** 1. Process a simple text file and print the top 3 most common words.

## 🗓️ Day 4

### Topic 10: Pandas Intro
* **Easy:** 1. Import pandas. 2. Create a DataFrame from a dictionary.
* **Medium:** 1. Load a real CSV file into a DataFrame and print the first 5 rows.
* **Hard:** 1. Write a DataFrame to a new CSV file without the index.

### Topic 11: Series & DataFrames Deep Dive
* **Easy:** 1. Select a single column. 2. Filter a DataFrame based on a single condition.
* **Medium:** 1. Filter using multiple conditions (AND/OR).
* **Hard:** 1. Update the values of a column conditionally.

### Topic 12: Grouping (Checkpoint 2)
* **Easy:** 1. Use `describe()`. 2. Group data by a categorical column and count rows.
* **Medium:** 1. Group by two columns and find the sum.
* **Mini Project 2 (Logic & Data Structures):** Raw Data Cleaner. Convert a list of dictionaries (simulated JSON) to a DataFrame, clean it using loops/lists, and output a grouped summary.

## 🗓️ Day 5

### Topic 13: Data Manipulation
* **Easy:** 1. Concatenate two DataFrames vertically. 2. Drop all rows with missing values.
* **Medium:** 1. Perform an inner merge on two DataFrames.
* **Hard:** 1. Fill missing values with the mean of the column.

### Topic 14: Debugging Mindset
* **Easy:** 1. Fix a missing parenthesis error. 2. Fix an indentation error.
* **Medium:** 1. Use `print()` statements to trace variable changes in a loop to find a logic error.
* **Hard:** 1. Identify a silent logical error (like using integer division `//` instead of `/`).

### Topic 15: Exceptions
* **Easy:** 1. Catch a `ZeroDivisionError`. 2. Raise an `Exception` manually.
* **Medium:** 1. Write a function that raises a `ValueError` if input is negative.
* **Hard:** 1. Implement a retry mechanism using a `while` loop and `try/except`.

## 🗓️ Day 6

### Topic 16: Try/Except/Finally & Custom Exceptions
* **Easy:** 1. Write a try/except/finally block where finally prints "Cleanup".
* **Medium:** 1. Define an empty custom exception class and raise it.
* **Hard:** 1. Create an API request simulator that raises a custom `NetworkError`.

### Topic 17: Regression Concepts (Checkpoint 3)
* **Easy:** 1. Generate a correlation matrix using pandas.
* **Medium:** 1. Identify a scenario where correlation exists but causation does not.
* **Mini Project 3 (Pandas & Debugging):** Corrupt Data Rescue. Debug a broken Pandas script, compute a correlation matrix, and identify related variables.

## 🗓️ Day 7

### Topic 18: Linear Regression (Hands-On)
* **Easy:** 1. Perform a train/test split. 2. Initialize LinearRegression.
* **Medium:** 1. Make a prediction on a trained model and calculate the R-squared score.
* **Hard:** 1. Reshape a 1D list into a 2D array and fit a model.

### Topic 19: Capstone Mini Project
* **Easy:** 1. Identify the target variable and drop NA values.
* **Medium:** 1. Run the train_test split and plot the target distribution.
* **Hard:** 1. Execute the entire pipeline end-to-end without errors.
